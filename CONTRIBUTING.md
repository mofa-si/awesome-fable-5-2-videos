# Contributing
Submit the original post URL, creator credit, and any public prompt. The post must be published after 2026-11-09T18:00:00Z and the creator must say it was made with Claude Fable 5.2.
- Do not invent or reconstruct prompts. Keep the original-language prompt verbatim.
- Credit the original creator, never a reposting account.
- Videos must be at most 300 seconds.
- Finished creative work and same-prompt model comparisons only; no reviews, tutorials or ads.
`data/collection.json` is the only source of truth. README files and `prompts/` are generated — do not edit them by hand.
