English · [简体中文](README.zh-CN.md)

A curated collection of videos made with Claude Fable 5.2 (Anthropic) and shared on X — launch films, 3D scenes in Blender and Three.js, browser games, interactive toys, music and short films written entirely in code, plus same-prompt model comparisons — with original files, creator credits and verbatim public prompts. - 24 entries include a verbatim public prompt; the rest are marked as not published — we never reconstruct prompts.
- Only original work posted after the Claude Fable 5.2 release, credited to its creator with a link to the source post. Each update is a bounded collection pass, not an exhaustive index.
